TOKO BAJU LINK BIO - STYLEKITA

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka folder.
3. Klik index.html.
4. Website akan terbuka di browser.

- Instagram
- WhatsApp
- Katalog baju
- Pencarian produk
- Filter Kaos/Kemeja/Hoodie
- Keranjang
- Tambah/kurang jumlah produk
- Total harga otomatis
- Checkout langsung ke WhatsApp
- Tampilan mobile/link-in-bio
